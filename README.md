# Portfolio Website

Personal portfolio website built with HTML, CSS and JavaScript.

## Features

- Responsive layout
- About me section
- Skills section
- Project showcase
- Contact links
- Dark mode toggle
- Theme saved in localStorage

## Technologies

- HTML
- CSS
- JavaScript

# Project Goal

This project was created to present my frontend development skills, showcase my portfolio project, and provide a single place where recruiters and employers can quickly review my work.

## Project Included

- Landing Page
- ToDo App
- Weather App
- Calculation App
- Quizz App
